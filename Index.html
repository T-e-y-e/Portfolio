About

Comfortable across the whole stack.

I'm a full-stack software engineer with over seven years of experience building production web, mobile and backend systems. On the frontend I work with React, Next.js, React Native and TypeScript; on the backend, with Node.js, Express, Spring Boot and Django, on top of PostgreSQL, MongoDB and MySQL.

Right now I'm building cross-platform booking experiences for EasyFynd, a hospitality platform, and leading frontend development for Kuhstomatica's AI-powered data product. Along the way I've built backend APIs in Java with Spring Boot, developed and maintained full-stack applications with third-party integrations, modernized frontend codebases and integrated payments and subscription billing, shipping features end to end with designers, engineers and product stakeholders in distributed Agile teams.

I'm always learning, whether that's picking up a new framework or going deeper into the tools I already use every day.
